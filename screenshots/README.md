# 截图目录说明

## 📸 如何添加截图

请将以下功能模块的截图文件放置在此目录下：

### 需要的截图文件清单

1. **login.png** - 登录页面截图
2. **home.png** - 首页（产业列表）截图
3. **detail-1.png** - 产业详情页截图（数据图表展示）
4. **detail-2.png** - 产业详情页截图（趋势分析）
5. **detail-3.png** - 产业详情页截图（统计信息）
6. **upload.png** - 数据上传页面截图（管理员功能）
7. **admin.png** - 管理后台截图（管理员功能）
8. **profile.png** - 个人中心截图

## 📝 截图规范

### 推荐尺寸
- **移动端截图**：750 x 1334px（iPhone标准尺寸）或实际设备截图

### 文件格式
- **推荐**：PNG格式（支持透明背景）
- **备选**：JPG格式（文件体积较小）

### 截图内容建议

#### 1. 登录页面 (login.png)
- 展示微信授权登录按钮
- 小程序标题

#### 2. 首页 (home.png)

- 数据统计总览（总产业数、总季度数等）
- 搜索框
- 底部TabBar导航

#### 3. 产业详情页 (detail-1.png, detail-2.png, detail-3.png)
**detail-1.png - 数据图表展示**
- 产业名称和时间周期

- 图例说明

**detail-2.png - 趋势分析**
- 趋势图表
- 数据对比
- 时间轴展示

**detail-3.png - 统计信息**
- 详细统计数据
- 数据表格或卡片
- 返回按钮

#### 4. 数据上传 (upload.png)
- 产业分类选择器

- 下载模板按钮
- 文件选择按钮

#### 5. 管理后台 (admin.png)
- 文件管理Tab
- 上传记录列表
- 搜索框
- 删除按钮
- 批量操作按钮

#### 6. 个人中心 (profile.png)
- 用户信息展示

- 退出登录按钮

## 📊 产业详情页的三个可视化页面说明

根据你的实际页面设计，三个详情页可能包含：
- **页面1**：主数据图表（柱状图、折线图等）
- **页面2**：趋势分析或对比图表
- **页面3**：统计汇总或其他维度的数据展示

请根据实际页面内容截图，文件命名为：
- `detail-1.png`
- `detail-2.png`  
- `detail-3.png`

## 🎨 截图技巧

### 方法一：微信开发者工具截图
1. 在微信开发者工具中打开小程序
2. 切换到"模拟器"视图
3. 使用系统截图工具（Windows: Win+Shift+S, Mac: Cmd+Shift+4）
4. 裁剪并保存为对应文件名

### 方法二：真机截图（推荐）
1. 在微信开发者工具中点击"预览"
2. 使用手机微信扫码
3. 在真机上截图（保留真实的小程序界面）
4. 传输到电脑并重命名

### 方法三：使用小程序截图API
```javascript
// 在小程序中使用
wx.canvasToTempFilePath({
  canvas: canvas,
  success: res => {
    wx.saveImageToPhotosAlbum({
      filePath: res.tempFilePath
    })
  }
})
```

## ✅ 上传步骤

1. 将截图文件放置在 `screenshots/` 目录下
2. 确保文件名与上述清单一致
3. 使用git添加文件：
   ```bash
   git add screenshots/*.png
   ```
4. 提交更改：
   ```bash
   git commit -m "docs: 添加功能截图"
   ```
5. 推送到GitHub：
   ```bash
   git push origin master
   ```

## 📌 注意事项

- ⚠️ 请勿在截图中暴露真实的用户OpenID、手机号等敏感信息
- ⚠️ 如需展示测试数据，请使用虚拟数据
- ⚠️ 确保截图清晰，文字可读
- ⚠️ 建议使用浅色主题截图，提高可读性
